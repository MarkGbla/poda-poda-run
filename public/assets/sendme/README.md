# SendMe branding

`logo.png` is a 512-pixel-wide copy of the logo served by the official
SendMe website at https://www.sendmesl.com/images/sendme-new-logo.png
(retrieved during implementation, 15 October 2026). Only resolution was changed.
Source website: https://www.sendmesl.com/.

The motorcycle, uniform and rider are original procedural stylizations guided
by the user's supplied reference image; they are not verified real-world uniforms.
The website's logo takes precedence over the generated reference lettering.
Brand approval may be required before public or commercial release. This file
does not assert a license or endorsement from SendMe.
